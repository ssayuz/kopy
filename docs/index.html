왜 kopy인가요?

영어 키워드 때문에 코딩이 어렵게 느껴졌다면, 한국어로 먼저 시작해 보세요.

한국어 키워드

만약·아니면·반복·함수·클래스·시도·예외까지 파이썬 문법을 한국어로 써요.

파이썬과 똑같이

파이썬으로 바꿔서 실행해서 표준 라이브러리, pip 패키지를 그대로 쓸 수 있어요.

전용 편집기

색칠, 줄 번호, 자동 들여쓰기. 코드를 쓰고 F5를 누르면 바로 실행돼요.

한국어 오류 메시지

“영나누기오류: 0으로 나눌 수 없어요”처럼 몇 번째 줄에서 무엇이 틀렸는지 알려줘요.

설치 한 번이면 끝

설치 파일을 실행하면 편집기, 명령어, 예제, 파일 연결까지 한 번에 준비돼요.

무료 · 오픈 소스

MIT 라이선스. 코드는 GitHub에 모두 공개되어 있어요.

시작하기

3분이면 첫 프로그램을 실행할 수 있어요.

  1. kopy-setup.exe를 받아 실행하고 ‘예’를 누르세요. Windows가 경고하면 “추가 정보 → 실행”을 누르세요.
  2. 바탕 화면의 kopy 편집기를 여세요.
  3. 출력("안녕, kopy!")을 쓰고 F5를 누르세요.
  4. 터미널에서는 kopy 파일.kopy로 실행할 수 있어요. 사용법은 python과 같아요.
